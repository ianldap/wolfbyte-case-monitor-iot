#  Monitor IoT de Conforto Acústico e Acessibilidade

Este projeto visa desenvolver um dispositivo embarcado capaz de monitorar o nível de ruído de um ambiente e informar, em tempo real, se o local está calmo, moderado ou ruidoso. O objetivo principal é auxiliar na identificação de ambientes potencialmente desconfortáveis para pessoas com hipersensibilidade auditiva.

Projeto desenvolvido para a fase Trainee (Subárea de Hardware - Equipe WolfByte) do Ramo Estudantil IEEE CEFET/RJ (2026.2).

## 🚀 Como Executar e Reproduzir
1. Clone este repositório: `git clone https://github.com/ianldap/wolfbyte-case-monitor-iot.git`
2. Abra o projeto na sua IDE (recomendado: VS Code com PlatformIO ou Arduino IDE).
3. Instale as dependências listadas acima.
4. Configure suas credenciais de Wi-Fi e do Broker MQTT no arquivo `config.h` (que será criado).
5. Compile e faça o upload para o ESP32.
